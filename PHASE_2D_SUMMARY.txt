ERROR HANDLING
================================================================================

Request Validation:
  ✅ Missing 'query' → HTTP 400
  ✅ Missing 'file_path' → HTTP 400
  ✅ Malformed JSON → HTTP 400
  ✅ Null body → HTTP 400

Security:
  ✅ Path traversal attempts → HTTP 403
  ✅ File outside project → HTTP 403
  ✅ Access outside allowed root → HTTP 403

Runtime Errors:
  ✅ Agent execution failure → Continue with other agents
  ✅ LLM unavailable → Fallback to template synthesis
  ✅ File not found → Return empty tabs or error
  ✅ Generic exception → HTTP 500 with error message

Graceful Degradation:
  • If LLM fails: Use keyword fallback for intent
  • If one agent fails: Others continue
  • If aggregation fails: Return raw agent results
  • If LLM synthesis fails: Use template fallback

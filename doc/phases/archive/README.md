# Archived Phase Documentation

**Purpose:** Historical phase documentation that is no longer current but retained for reference.

---

## Why This Folder Exists

Phase documentation accumulates over time as the project evolves. Some docs become:
- **Obsolete**: No longer accurate or relevant
- **Superseded**: Replaced by newer, better documentation
- **Historical**: Useful only for understanding what was tried before

Rather than delete these, we archive them here so:
1. **History is preserved** → You can see what was planned/tried
2. **Lessons are kept** → Anti-patterns and failed approaches documented
3. **Search is possible** → Find old approaches that might be relevant again

## How to Use This Archive

**When to read here:**
- Understanding what was tried before
- Learning from mistakes/dead ends
- Finding if something was already attempted
- Historical context for current decisions

**When NOT to use:**
- For current development → Use `/phases/README.md`
- For current architecture → Use `/architecture/`
- For current guides → Use `/guides/`

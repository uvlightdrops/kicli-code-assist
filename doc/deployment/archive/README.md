## Why This Folder Exists

Deployment approaches evolve as infrastructure matures. Old docs show:
- **What was tried** → Earlier deployment strategies
- **Why they changed** → Problems with old approach
- **Historical patterns** → What deployment looked like before

Rather than delete, we archive here to:
1. **Preserve learning** → See failed/successful approaches
2. **Show evolution** → How deployment strategy improved
3. **Prevent regressions** → Don't repeat old mistakes

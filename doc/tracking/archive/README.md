# Archived Session & Tracking Documentation

**Purpose:** Old session summaries and tracking documents from completed work.

---

## Why This Folder Exists

As sessions complete and phases finish, tracking docs accumulate. Old docs become:
- **Completed**: Session finished, now historical
- **Superseded**: Newer tracking replaces older
- **Reference**: Shows what was attempted

Rather than delete, we archive here to:
1. **Preserve history** → See session-by-session progress
2. **Track evolution** → Understand how blockers were resolved
3. **Learn patterns** → See what worked/didn't work

---

## How to Use This Archive

**When to read:**
- Understanding how a blocker was resolved
- Seeing what was tried in earlier sessions
- Tracking long-term progress

**When NOT to use:**
- For current progress → Use `/tracking/README.md`
- For current session work → Use active session tracking docs

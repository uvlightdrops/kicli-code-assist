# Archived Testing Documentation

**Purpose:** Old test reports and superseded testing strategies.

---

## Why This Folder Exists

Test reports accumulate as phases complete. Old reports become historical records showing:
- What was tested in earlier phases
- Test coverage evolution
- When/why test strategies changed

Rather than delete, we keep them for:
1. **Traceability** → See how testing evolved
2. **Learning** → Understand what wasn't caught before
3. **Comparison** → Compare test coverage over time

---

## How to Use This Archive

**When to read:**
- Comparing test coverage metrics over time
- Understanding testing approach evolution
- Finding test cases that were tried before

**When NOT to use:**
- For current test results → Use `/testing/README.md`
- For current test strategy → Use active `/testing/*.md` files

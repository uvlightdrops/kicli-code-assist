# Archived Guides & Documentation

**Purpose:** Outdated setup guides, tutorials, and how-to documentation.

---

## Why This Folder Exists

Guides become outdated as the system evolves. Old guides remain useful for:
- **Historical reference** → Understand what changed
- **Migration paths** → See what had to change when
- **Learning** → Understand why new approach is better

Rather than delete, we archive here to:
1. **Maintain continuity** → See documentation evolution
2. **Explain changes** → Why old guide doesn't work anymore
3. **Prevent regressions** → Don't repeat old mistakes

---

## How to Use This Archive

**When to read:**
- Understanding why a guide changed
- Checking if an old workaround is still needed
- Learning about deprecated approaches

**When NOT to use:**
- For current setup → Use `/guides/README.md`
- For current procedures → Use active guides in `/guides/`

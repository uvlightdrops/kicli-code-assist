# Archived Architecture Documentation

**Purpose:** Superseded architecture documentation retained for historical reference.

---

## Why This Folder Exists

Architecture evolves as systems mature. Some design docs become:
- **Superseded**: Replaced by better designs
- **Partially Relevant**: Only parts are still useful
- **Historical**: Context for why current design was chosen

Rather than delete, we archive here so the evolution is traceable.

---

## How to Use This Archive

**When to read:**
- Understanding design evolution
- Comparing old vs. new approaches
- Learning from architectural decisions

**When NOT to use:**
- For current implementation → Use `/architecture/README.md`
- For current design → Use active `/architecture/*.md` files

---

## Searching This Archive

Look here if:
- You're refactoring something and want to see why it was designed that way
- You want to understand rejected design approaches
- You're writing ADRs (Architecture Decision Records) and need historical context

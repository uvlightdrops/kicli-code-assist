# Archived Feature Documentation

**Purpose:** Documentation for features that were removed, replaced, or superseded.

---

## Why This Folder Exists

As the project evolves, some features:
- **Get replaced** → Better version implemented
- **Get removed** → No longer needed
- **Get refactored** → API/behavior changes

Old feature docs are archived to:
1. **Show feature history** → What features existed
2. **Explain deprecation** → Why feature was removed
3. **Aid migration** → How to migrate from old to new feature

---

## How to Use This Archive

**When to read:**
- Understanding feature history
- Finding replacement for removed feature
- Checking if something was already attempted

**When NOT to use:**
- For current features → Use `/features/README.md`
- For current feature docs → Use active docs in `/features/`
